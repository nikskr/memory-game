## Описание игры ✏

На поле 16 карточек: 8 разных изображений, каждое встречается дважды. В начале игры все карточки лежат рубашкой вверх. Рубашки одинаковые и не раскрывают содержимое карточек. Переворачивайте по две карточки за один ход, стараясь запомнить их расположение. Если изображения совпали, они остаются открытыми, а если нет — закрываются через мгновение. Ваша цель — найти все 8 пар за минимальное количество ходов!

## Как запустить проект локально 🚀

Вы можете запустить проект на своем компьютере, выполнив следующие шаги:

### Предварительные требования

- Установленный [Git](https://git-scm.com)
- Установленный редактор [Visual Studio Code](https://visualstudio.com) с расширением **Live Server**

### Пошаговая инструкция

#### Шаг 1: Клонирование репозитория

Откройте терминал (или командную строку) и выполните команду:

```bash
git clone https://github.com/nikskr/memory-game
```

Перейдите в папку проекта:

```bash
cd memory-game
```

#### Шаг 2: Открытие в Visual Studio Code

Откройте скачанную папку в редакторе:

```bash
code .
```

_(Или откройте VS Code вручную и выберите `File` -> `Open Folder...` -> выберите папку проекта)_

Перейдите в ветку проекта:

```bash
git checkout memory-game
```

#### Шаг 3: Запуск через Live Server

1. В проводнике VS Code откройте главный файл — `index.html`.
2. Нажмите на кнопку **Go Live** в правом нижнем углу строки состояния VS Code.
3. _Альтернативный вариант:_ Кликните правой кнопкой мыши по файлу `index.html` и выберите **Open with Live Server**.

После этого проект автоматически откроется в вашем браузере по адресу `http://127.0.0.1:5500/index.html`.
